title: "Overview"
description: "What the pi ACP adapter does and where its responsibility ends"
---

`acp-go-pi` runs the pi coding agent behind an Agent Client Protocol (ACP)
JSON-RPC connection. A host either launches the `acp-go-pi` binary and speaks
ACP over stdio, or embeds the Go package and calls `piacp.Serve`. Either way
the host drives pi through standard ACP methods instead of the interactive
terminal UI.

## What the adapter owns

The adapter is a thin translation layer between ACP and the local `pi` CLI in
RPC mode. It owns:

- ACP protocol mapping and the pi subprocess lifecycle (one long-lived
  `pi --mode rpc` process per ACP session, each in an isolated per-session
  agent directory with a scrubbed environment).
- Streaming pi's JSONL RPC events into ACP session updates.
- The permission and elicitation dialogs themselves — pi deliberately ships no
  built-in permission system, so the adapter supplies one through a
  wrapper-owned pi extension.
- The MCP client — pi deliberately ships no built-in MCP support, so the
  adapter supplies a dependency-free pi extension that connects the session's
  declared MCP servers.
- Model configuration, slash-command projection, optional raw events, and
  optional durable session storage.
- Optional provider-auth brokerage through Pi's native auth catalog and
  `AuthStorage`, with a durable values-free ownership ledger.

## What the adapter does not own

Provider credential values stay with Pi. A host may inject a key or seeded file,
or configure a durable Pi home and ledger root to expose seven `_pi/auth/*`
extension legs. The adapter brokers dialogs, flow state, residence proof, and a
fenced disconnect, but never returns credential material or stores it in the
ledger. See [Authentication](/docs/features/authentication).

## Extension surface

Public extension methods are intentionally narrow, and all pi-specific
metadata lives under the `_meta.pi` namespace:

| Method | Purpose |
| --- | --- |
| `_pi/session/fork` | Fork a stored or active session. |
| `_pi/rawEvent` | Emit opt-in, bounded raw pi RPC events. |
| `_pi/auth/methods`, `_pi/auth/authorize`, `_pi/auth/callback`, `_pi/auth/status`, `_pi/auth/cancel`, `_pi/auth/inventory`, `_pi/auth/disconnect` | Optional session-scoped provider catalog, connection flow, proof, and removal legs. |
