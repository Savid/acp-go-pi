## Entry points

`NewAgent(opts...)` constructs an agent for direct method use.
`Serve(ctx, input, output, opts...)` serves ACP over JSON-RPC
streams.

```go
err := piacp.Serve(ctx, input, output,
    piacp.WithExecutablePath("/usr/local/bin/pi"),
    piacp.WithScratchDir("/tmp/pi-scratch"),
    piacp.WithDefaultModel("openai/gpt-4o"),
)
```

## Host authority

`WithHostAuthority(HostAuthority)` selects managed execution. The
public authority contract consists of `HostAuthority`,
`NativeRequest`, `NativeProcess`,
`NativeResult`, and these stable `errors.Is` sentinels:

- `ErrHostAuthorityUnavailable`
- `ErrContainmentIncomplete`
- `ErrNativeTreeBusy`

`NativeProcess.Wait` is the terminal containment proof.
`Revoke` initiates host-owned teardown. A supplied nil or unusable
authority fails initialization before native mutation or launch. Omitting the
option selects ordinary same-account execution.

The interface includes `ReadNativeAppendLog(context.Context, string, uint64)
([][]byte, error)` and `WriteNativeAppendLog(context.Context, string, [][]byte)
error`. This adapter does not invoke either for provider state.

## Agent options

| Option | Purpose |
| --- | --- |
| `WithExecutablePath` | Configure the Pi executable selector. Managed mode passes it to the host without local resolution. |
| `WithHostAuthority` | Route every managed native launch and tree transition through the host. |
| `WithHome` | Configure a durable ordinary-mode PI_CODING_AGENT_DIR. Managed mode rejects this option before materialization. |
| `WithScratchDir` | Parent for ephemeral session and probe trees, and for the extension store sessions share. |
| `WithDefaultModel` | Default model as provider/id. |
| `WithPiDirectAPI` | Enable direct quota reads inside Pi; true by default. False returns unavailable/disabled for supported providers. |
| `WithEnv` | Static environment overlay for every pi process. `ACP_GO_PI_EXTRA_PATH_DIRS` is refused under every spelling. Names follow the session `env` rule with `PATH` allowed: a key is non-empty and free of `=` and NUL, the value is free of NUL, the injection names `NODE_OPTIONS`, `BASH_ENV`, `ENV`, and any `LD_` or `DYLD_` prefix are refused under the platform identity, the private adapter namespace is refused under every spelling, and two spellings of one Windows variable are refused; a refusal fails Agent construction. |
| `WithAmbientEnvironment` | Replaces the adapter's own process environment as the block ordinary execution inherits from. The same allowlist and scrub apply to it, and `WithEnv` and session `env` overlay it; a supplied map is folded in sorted key order. Nil inherits from the adapter's process; an empty map inherits nothing. An entry that could not be an environment entry fails Agent construction. Every mode validates it; managed execution reads nothing from it. |
| `WithSeedFiles` | Materialize exact files before native-tree prepare. |
| `WithSessionStore` | Install durable session mirroring. |
| `WithSessionStoreLoadTimeout` | Bound store load and list operations. |
| `WithConcurrencyLimits` | Cap active sessions and concurrent client calls. |
| `WithImageLimits` | Bound decoded prompt and emitted image bytes. |
| `WithInputHandoffRoot` | Allow handoff-form prompt images below one absolute read root. |
| `WithTurnTimeout` | Bound a prompt turn. |
| `WithProviderAuthRoot` | Enable the values-free provider-auth ledger with WithHome in ordinary mode. |
| telemetry options | Configure logging and OpenTelemetry providers. |

## Per-session options

Build `_meta.pi.options` with `NewPiOptions`. Supported
options select the model, reasoning level, permission mode, automatic retry,
explicit environment, and additional child search directories.
`WithPiOutputSchema` is refused because Pi has no native
structured-output surface. `ValidatePiSessionMeta(meta)` returns the refusal
a session-establishing request carrying that `_meta` map would receive, or
nil, without an agent; see [Metadata](/docs/reference/meta).

## Request and store helpers

The package provides typed builders for session creation, load, resume, fork,
prompt, cancel, configuration, list, and delete requests, plus stdio and HTTP
MCP declarations. `SessionStore` mirrors Pi JSONL rows; lifecycle
boundary rows remain in their separate current-format subpath.

## Quota types

`RateLimitsMethod` names `_pi/rateLimits`, dispatched through
`Agent.HandleExtensionMethod`. `RateLimitsRequest` selects `providerId` and
optional `sessionId`; `RateLimitsResponse` contains `providerId`, `availability`,
optional `reason`, and `pools`. `RateLimitPool`, `RateLimitWindow`,
`RateLimitBalance`, and `RateLimitMoney` describe the normalized observations.
Optional numbers use pointers so measured zero remains present. See
[Rate limits](/docs/reference/acp-methods#rate-limits) for selection and availability.
