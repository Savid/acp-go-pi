The full, authoritative API — signatures, types, and doc comments — is on
[pkg.go.dev](https://pkg.go.dev/github.com/savid/acp-go-pi). This page indexes
the public surface; it does not restate godoc.

## Entry point

`Serve(ctx, input, output, opts...)` runs the agent over a pair of JSON-RPC
streams:

```go
err := piacp.Serve(ctx, input, output,
	piacp.WithExecutablePath("/usr/local/bin/pi"),
	piacp.WithScratchDir("/tmp/pi-scratch"),
	piacp.WithDefaultModel("openai/gpt-4o"),
	piacp.WithSessionStore(store),
)
```

Hosts that need direct method access can construct `*Agent` with `NewAgent`;
stream-based hosts normally use `Serve`. `Options` and `ConcurrencyLimits`
are the exported configuration value types behind the functional options.

`ErrProcessContainmentIncomplete` is the stable `errors.Is` discriminator
returned when the selected native boundary does not complete. `Serve` returns
an `Agent.Close` error carrying this sentinel even when the stream loop would
otherwise return normally or with context cancellation. A host that receives
it must retain or quarantine any resources the native runtime may still
reach. It does not mean that every descendant can be inventoried on Darwin.

`Agent.ContainmentMode()` returns `RuntimeContainmentAuthoritative` on Linux
and Windows, `RuntimeContainmentBestEffort` on an opted-in Darwin agent, and
`RuntimeContainmentUnavailable` otherwise. Darwin fails closed unless
`WithDarwinBestEffortContainment` is supplied; that option is invalid off
Darwin.

## Process options

| Option | Purpose |
| --- | --- |
| `WithExecutablePath` | Set the pi CLI path (default: search `PATH`). |
| `WithProcessIsolation` | Mandatory non-root UID/GID and complete replacement base environment for every pi process and supervisor. |
| `WithScratchDir` | Parent directory for all ephemeral on-disk state (isolated per-session agent and session directories, hydration temp files, probe dirs). Empty means the system temp directory; created `0700` when missing. |
| `WithHome` | Durable per-instance pi agent directory (`PI_CODING_AGENT_DIR`) every session runs against. Omitted, each session gets an isolated agent directory under the scratch parent, which disables pi's cross-process credential refresh lock and leaves the provider-auth surface unadvertised. |
| `WithProviderAuthRoot` | Absolute, host-owned, durable directory holding the values-free provider-auth ledger; created mode `0700`. Omitted, or naming a root that cannot be prepared, leaves every `_pi/auth/*` leg unadvertised; a relative path is rejected at construction. See [Authentication](/docs/features/authentication). |
| `WithProviderAuthDirectHome` | Declared and rejected: pi has no account-level provider-auth leg to gate. A non-empty value is rejected at session start with the unsupported-option error for field `providerAuthDirectHome`. |
| `WithDefaultModel` | Default model for new sessions, as `"provider/id"`. |
| `WithEnv` | Overlay environment variables on `ProcessIsolation.BaseEnvironment` for every pi child. Invalid names plus `NODE_OPTIONS`, `BASH_ENV`, `ENV`, `LD_*`, and `DYLD_*` are rejected; ambient variables are never inherited. |
| `WithExtraPathDirs` | Prepend absolute directories, in order, to the `PATH` of every pi child. The sanctioned counterpart to the rejected raw `PATH` key; a relative entry or an embedded list separator fails session start. |
| `WithSeedFiles` | Write files into each isolated agent directory. Seeded extensions, prompts, and skills in their conventional subdirectories are loaded by exact path. |
| `WithSessionStore` | Install durable session storage. |
| `WithSessionStoreLoadTimeout` | Bound store load/list operations used during resume. |
| `WithConcurrencyLimits` | Cap active sessions and concurrent client calls. |
| `WithImageLimits` | Decoded-byte limits for prompt image input and emitted image output (`MaxInputBytesPerImage`, `MaxInputBytesPerPrompt`, `MaxOutputBytesPerImage`, `MaxOutputBytesPerToolCall`); each defaults to 6 MiB, an explicit zero disables that policy limit, and negative values are rejected at construction. |
| `WithInputHandoffRoot` | Absolute read root for handoff-form prompt images. Omitted (the default) rejects the handoff form; a relative path is rejected at construction. The adapter only reads under it and never writes, moves, or removes anything there. |
| `WithTurnTimeout` | Bound one prompt turn; expiry fails the turn with cause `timeout` (default: no deadline). |
| `WithRuntimeResourceHooks` | Host admission hooks for native-process roots and adapter scratch roots. |
| `WithDarwinBestEffortContainment` | Explicitly accept Darwin process-group containment and its escaped-descendant risk. Invalid on other platforms. |

## Per-session options

`PiOptions` is the typed builder for `_meta.pi.options`; construct it with
`NewPiOptions` and attach it with `WithSessionPiOptions`:

| Option | Purpose |
| --- | --- |
| `WithPiModel` | Session model as `"provider/id"`. |
| `WithPiEnv` | Extra environment variables for this session's pi process. |
| `WithPiThinkingLevel` | Reasoning level: `off`, `minimal`, `low`, `medium`, `high`, `xhigh`, or `max`. |
| `WithPiPermission` | Permission mode: `ask` (default) or `allow`. |
| `WithPiAutoRetry` | Opt in to pi's native automatic retry of transient provider errors (5xx, timeouts). Default `false`: a native failure surfaces once, immediately, with the real cause. |
| `WithPiOutputSchema` | Reserved for API symmetry; pi has no native structured-output surface, so setting it fails closed at session start. |

## Request helpers and store types

Request builders: `NewSessionRequest`, `LoadSessionRequest`,
`ResumeSessionRequest`, `ForkSessionRequest`, `CallForkSession`,
`PromptRequest`, `TextPromptRequest`, `SetConfigOptionRequest`,
`SetModelRequest`, `DeleteSessionRequest`, `ListSessionsRequest`,
`WithSessionMCPServers`, `WithSessionAdditionalDirectories`,
`WithSessionMeta`, `WithSessionRawEvents`, `WithSessionOutputSchema`,
`WithListSessionsCwd`, `WithListSessionsCursor`, `WithListSessionsMeta`,
`StdioMCPServer`, `HTTPMCPServer`.

`PromptRequest(sessionID, turnNonce, blocks...)` and
`TextPromptRequest(sessionID, turnNonce, text)` require a fresh, unguessable
nonce per turn. `CancelRequest(sessionID, turnNonce)` must reuse the active
turn's nonce. A route nonce must be non-empty and at most 4096 bytes. These
builders fail closed for an invalid nonce by omitting route metadata, so the
agent rejects the resulting prompt or active-turn cancellation.

`RuntimeResourceHooks` exposes `AcquireNativeRoot`, `ReserveScratchRoot`,
`ObserveProcess`, `ObserveProcessSnapshot`, `ObserveStartupStage`, and
`ObserveContainment`.
Admission callbacks receive `runtime`, `session`, `prompt`, or `discovery`; nil
means unbounded standalone operation. Pi acquires discovery and per-session
native permits immediately before their launches, reserves scratch before
making the isolated agent directory, and releases only after the selected
boundary completes and directory deletion succeeds. Pi is lockless and emits
no home-lock-supervisor count. Provider descendant snapshots are emitted only
when inventory is authoritative; Darwin best-effort emits no provider
snapshot, including zero. `ObserveContainment` is called once with the
effective mode. Startup observations distinguish spawn, readiness,
configuration, and native session setup.

Session-store surface: `SessionStore`, `SessionKey`, `SessionSummary`,
`SessionStoreReplacement`, `InMemorySessionStore`, and the constants
`SessionStoreFormat` and `SessionStoreMainSubpath`.
