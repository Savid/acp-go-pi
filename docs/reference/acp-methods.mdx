## Methods

Core methods handled through the ACP SDK connection: initialize, session
create/load/resume/list/delete, prompt, cancel, close, authenticate, logout,
and the session configuration methods. Unsupported methods return a uniform
JSON-RPC method-not-found error.

`session/close` fences admission, denies/cancels and joins every admitted host
dialog/action, then contains the exact native generation before joining prompt
settlement and any turn/restore/configuration holder. Only a complete join
permits the durable close boundary, terminal lifecycle output, directory removal, and resource
release. `session/delete` first commits its tombstone and persistence fence,
then runs that same interaction-barrier, containment, and join contract. An
incomplete interaction, containment, or holder join is retained under exact
Agent ownership and returned as
`ErrContainmentIncomplete`; it is never logged and discarded.

## Extensions

| Method | Direction |
| --- | --- |
| `_pi/session/fork` | client to agent |
| `_pi/rawEvent` | agent to client |

### `_pi/session/fork`

Forks a session by duplicating the parent's active branch into a new pi
session with a fresh session id; the parent linkage is recorded in the new
session's header. Params and result reuse the SDK's fork payload shapes, built
with `ForkSessionRequest` and called through `CallForkSession`. Stable
`session/fork` is not routed — it returns method-not-found; the extension
method is the only fork route. Forking a session that has no conversation
entries yet is rejected with a structured invalid-params error, because pi
cannot duplicate an empty branch.

### No `_pi/rateLimits`

pi is bring-your-own-key across many providers and exposes no
subscription-usage source, so this adapter does not implement a
`_pi/rateLimits` extension; a call returns the uniform JSON-RPC
method-not-found error.

## Turn-failure contract

A native turn failure terminates `session/prompt` with a JSON-RPC error and no
`PromptResponse`; it is never reported as an ACP stop reason. Every failure
uses one uniform shape so a host can classify it without vendor parsing. The
error is JSON-RPC code **`-32603`** with a `data` object:

| Field | Value |
| --- | --- |
| `error` | `pi_turn_failed` |
| `cause` | one of the causes below |
| `message` | the bounded native cause text, except where the cause contract below requires a fixed redacted message |

The `cause` vocabulary:

| Cause | Meaning |
| --- | --- |
| `process_exit` | The pi process died, or the version probe would not run; `message` carries the real exit status and the stderr line naming the cause. |
| `transport` | pi's stdout closed or the event stream broke mid-turn. |
| `provider` | pi reported a provider error for the turn (bad key, quota, upstream failure); `message` carries pi's error text. |
| `timeout` | A `WithTurnTimeout` deadline expired; the native turn was aborted and reached its native boundary before return. In managed mode the host authority's `Wait` result must settle before the error is returned. |
| `extension` | A pi extension threw. The wrapper-owned extensions are the permission bridge and the MCP client, so the cycle fails closed rather than running on under an admission nobody granted. `message` is the fixed string `a pi extension failed`; the extension path and the thrown text are withheld from the wire and from the log, because thrown text can carry tool input. |

Except for the fixed redacted `extension` message, `message` is bounded at 2048
bytes and carries the native cause, not a transcript. The cap is applied to the
original byte prefix before invalid UTF-8 repair or whitespace trimming, so
leading padding and a cut multibyte rune can never expose a later suffix. The adapter's `slog`
output records only fixed failure classifications, safe identifiers, and
adapter stages. Native stderr, provider/user/tool content, arbitrary native
event names, panic payloads, and action/client error strings are never copied
into logs.

A provider failure leaves the session addressable: the next `session/prompt`
re-drives the turn. Native stdout is strict LF-delimited JSONL: the first
nonblank malformed record, or any unterminated EOF record, terminalizes that
client with a fixed structural transport failure. Later records are not read,
and the exact failed generation is contained without a fabricated lifecycle
terminal.

## Caller-error contract

An unsupported or unusable config field is rejected with JSON-RPC **`-32602`**
whose `data` is exactly two keys,
`{"error":"unsupported","field":"<json path>"}` — including
`session/set_session_config_option`, which no longer echoes the caller's value
or a native error string back.

`unsupported` and `missing` are distinct verdicts and are never collapsed.
`unsupported` names a value that is present and refused — an unknown option, a
reserved key on a surface where it has no meaning, a malformed member.
`missing` names a value the contract requires and the caller left out, and it
appears on exactly two paths: the reserved route envelope and, while the
lifecycle capability is enabled, the prompt correlation value. A host reading
`missing` adds the key; a host reading `unsupported` on the same bare path
stops sending it on that surface.

| Case | `data` |
| --- | --- |
| Unknown or unloaded session | `{"error":"unknown session","field":"sessionId"}` |
| Relative `cwd` on `session/new`, `session/load`, `session/resume`, or `_pi/session/fork` | `{"error":"unsupported","field":"cwd"}` |
| `_pi/*` params that cannot be decoded, or fail validation as a whole | `{"error":"unsupported","field":"params"}` (the member instead, when one member is at fault) |
| Absent `_meta["acp-go.dev/route"]` on `session/prompt` | `{"error":"missing","field":"_meta[\"acp-go.dev/route\"]"}` |
| Malformed route value | `{"error":"unsupported","field":"_meta[\"acp-go.dev/route\"].<member>"}` |
| Absent `_meta["acp-go.dev/lifecycle"]` on `session/prompt` while the capability is enabled | `{"error":"missing","field":"_meta[\"acp-go.dev/lifecycle\"]"}` |
| Malformed lifecycle correlation value | `{"error":"unsupported","field":"_meta[\"acp-go.dev/lifecycle\"].<member path>"}` |
| Lifecycle key on a surface that carries none | `{"error":"unsupported","field":"_meta[\"acp-go.dev/lifecycle\"]"}` |
| SSE or ACP MCP transport | `{"error":"unsupported","field":"mcpServers[N]","server":"<name>"}` |
| MCP entry with no transport | `{"error":"no_transport","field":"mcpServers[<i>]"}` |
| Empty or duplicate MCP name | `{"mcpServers[<i>].name":"required"}` / `"duplicate"` |
| Undecodable or past-end list cursor | `{"cursor":"invalid cursor"}` / `{"cursor":"cursor is past end"}` |
| `authenticate` with an unknown method id | `{"methodId":"<the id you sent>"}` |
| Fork of an empty session | `{"error":"cannot fork an empty session","field":"sessionId"}` |

Route validation runs before the lifecycle correlation value is read, so a
prompt wrong in both ways reports the route refusal alone. `session/cancel` is
a notification and answers nothing, so its refusals are wire-silent; the cancel
is never applied.

Image rejections carry the structured image data documented in
[Prompt streaming](/docs/core/prompt-streaming).

A request the client cancels with `$/cancel_request` is answered **`-32800`**
with no `data`, ahead of whatever error the in-flight handler returned. An
adapter-internal deadline is never reported as a cancel.

## Off-prompt internal errors

Every **`-32603`** away from a prompt turn carries exactly one closed
`pi_`-prefixed token in `data.error`. The JSON-RPC `message` stays the protocol
constant `Internal error`, `data` is always present, and `data` never carries a
`message` member: no Go error text and no native text reaches a client on these
paths. The reason is in the adapter log.

| `data.error` | Raised by |
| --- | --- |
| `pi_invalid_options` | An option the embedding host handed `NewAgent` and this adapter refuses. Optional `field` names the option when exactly one is at fault. Delivered on `initialize` and on every session-establishing entry point, because an embedded host can open a session and prompt without ever handshaking. A construction verdict is never `-32602`: the caller's params were valid, and it is the constructed agent that cannot serve them. |
| `pi_restore_failed` | `session/load`, `session/resume`, or `_pi/session/fork` found a store entry it could not restore — an unreadable store, a native log with no lifecycle boundary, a row count the boundary disagrees with, or a stored image artifact the store can no longer reproduce. The entry is neither deleted nor tombstoned. |
| `pi_session_poisoned` | A session whose admission is permanently fenced by a native invariant failure. Always carries `cause`, one of the closed tokens below. |
| `pi_internal_failure` | Everything unclassified. Optional `class` is the closed token `native_start`, which names a native pi process that could not be started or configured for a session — the version probe, the spawn, or the post-spawn command sequence. |

The `pi_session_poisoned` `cause` vocabulary:

| `cause` | Meaning |
| --- | --- |
| `command_catalog_undelivered` | The required session-open command catalog was not delivered. |
| `lifecycle_snapshot_undelivered` | The required session-open lifecycle snapshot was not delivered. |
| `session_open_gate_unreleased` | The session-open generation gate could not be released. |
| `native_session_identity_drift` | The native session id stopped matching the ACP session it was opened for. |
| `native_stream_failed` | The native JSONL event stream failed. |
| `outbox_retention_exceeded` | An outbox or startup prefix reached its retention bound, so ordering could no longer be guaranteed. |
| `native_invariant_violated` | pi produced a record its generation cannot place. |
| `adapter_panic` | An adapter goroutine driving the generation panicked. |
| `native_relaunch_failed` | The native process relaunch could not be set up. |
| `lifecycle_stream_failed` | An agent-origin cycle could not be opened on, or delivered to, the lifecycle stream. |
| `agent_cycle_settlement_failed` | An agent-origin cycle's settlement step failed. |
| `prompt_acceptance_failed` | The native prompt acceptance boundary failed. |
| `lifecycle_action_failed` | A lifecycle action request could not be registered, announced, or resolved. |
| `native_interaction_unsettled` | A native interaction response did not finish before cancellation. |

`pi_turn_failed` above is the prompt-turn token and is unaffected by this rule;
`pi_auth_failed` is the `-32000` provider-auth token. This adapter runs one pi
process per ACP session rather than a shared runtime, so it emits no
runtime-unavailable token at all: a dead process fences its own session and the
next prompt relaunches it.

<Note>
This adapter advertises no standard ACP `authenticate` method, so a provider
failure during a prompt is a `provider` failure under `-32603`. When the
optional Pi provider-auth broker is enabled, its `_pi/auth/*` extension legs
can return `-32000` with the closed `pi_auth_failed` cause shape; they never
return credential material. A user cancel that races a timeout resolves as a
successful `cancelled` response, not a failure.
</Note>
