`acp-go-pi` speaks ACP over stdin/stdout. Flags use Go's single-dash
syntax.

```sh
acp-go-pi -path /usr/local/bin/pi -scratch-dir /tmp/pi-scratch -model openai/gpt-4o
```

## Flags

| Flag | Purpose |
| --- | --- |
| `-path` | Pi executable; default searches the captured ordinary PATH. |
| `-home` | Durable per-instance PI_CODING_AGENT_DIR; empty uses ephemeral session state. |
| `-scratch-dir` | Parent for ephemeral session and version-probe trees. |
| `-provider-auth-root` | Durable values-free provider-auth ledger root; requires -home. |
| `-model` | Default model as provider/id. |
| `-seed-file` | Materialize relpath=hostpath in each session agent directory; repeatable. |
| `-debug` | Emit debug logs to stderr. |
| `-version` | Print adapter version and exit. |

## Execution boundary

The CLI runs Pi ordinarily as the command's account. Host-authority execution
is available only to embedded Go hosts through `WithHostAuthority`;
a borrowed capability cannot be represented by a configuration file or
command-line flag.

## Embedded-only configuration

Session stores, turn timeouts, concurrency limits, explicit environment
overlays, image limits, input handoff roots, telemetry providers, and host
authority are configured through the [Go API](/docs/reference/go-api).
