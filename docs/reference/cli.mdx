<code>acp-go-pi</code> speaks ACP over stdin/stdout. Flags use Go's single-dash
syntax.

~~~sh
acp-go-pi -path /usr/local/bin/pi -scratch-dir /tmp/pi-scratch -model openai/gpt-4o
~~~

## Flags

| Flag | Purpose |
| --- | --- |
| <code>-path</code> | Pi executable; default searches the captured ordinary PATH. |
| <code>-home</code> | Durable per-instance PI_CODING_AGENT_DIR; empty uses ephemeral session state. |
| <code>-scratch-dir</code> | Parent for ephemeral session and version-probe trees. |
| <code>-provider-auth-root</code> | Durable values-free provider-auth ledger root; requires -home. |
| <code>-model</code> | Default model as provider/id. |
| <code>-seed-file</code> | Materialize relpath=hostpath in each session agent directory; repeatable. |
| <code>-debug</code> | Emit debug logs to stderr. |
| <code>-version</code> | Print adapter version and exit. |

## Execution boundary

The CLI runs Pi ordinarily as the command's account. Host-authority execution
is available only to embedded Go hosts through <code>WithHostAuthority</code>;
a borrowed capability cannot be represented by a configuration file or
command-line flag.

## Embedded-only configuration

Session stores, turn timeouts, concurrency limits, explicit environment
overlays, image limits, input handoff roots, telemetry providers, and host
authority are configured through the [Go API](/docs/reference/go-api).
