## Ordinary boundary

Without `WithHostAuthority`, Pi runs as the adapter account. The
adapter owns the direct process lifecycle but does not claim whole-containment
vacancy. Hosts requiring a stronger boundary must provide one explicitly.

The environment is captured once. Ambient provider credentials, loader hooks,
shell hooks, Node hooks, and adapter-private values are removed.
`WithEnv` and per-session Pi options are deliberate overlays.
Session PATH replacement is rejected; absolute
`WithPiExtraPathDirs` entries are prepended to the child search path.

## Borrowed host authority

`WithHostAuthority` borrows four operations from the embedding host:
`NativeEnvironment`, `PrepareNativeTree`,
`StartNative`, and `ReclaimNativeTree`. The adapter never
selects accounts or changes filesystem ownership itself.

The host supplies the complete base environment and validates executable,
working-directory, and tree intent independently. The adapter adds its bounded
session overlay and passes the exact result to `StartNative`.

## Tree ownership

A runtime tree is fully materialized before `PrepareNativeTree`.
After prepare succeeds, the adapter performs no read, write, stat, walk,
resolution, or removal below that tree. Natural completion or shutdown must
settle through `NativeProcess.Wait`; only then may
`ReclaimNativeTree` return it to the adapter. Removal occurs only
after successful reclaim.

`ErrNativeTreeBusy` means reclaim changed nothing because a process
handle is still live. Failed or uncertain reclaim wraps
`ErrContainmentIncomplete` and leaves host cleanup registered.

## Cancellation and authority loss

Pi protocol shutdown and stdio closure happen before `Revoke`.
`Revoke` initiates host-owned teardown, and `Wait` proves
root exit, descendant vacancy, and containment cleanup. Caller cancellation
bounds only that caller's wait.

`ErrHostAuthorityUnavailable` stops further managed native
admission. Containment uncertainty fails closed and never falls back to
ordinary process creation.

Managed mode rejects `WithHome` before creating a runtime tree. A
successful prompt or fork is mirrored only after the generation's sole
`Wait` completes and `ReclaimNativeTree` succeeds.

## Provider authentication

Pi's seven provider-auth extension methods are available only in ordinary mode
with both `WithHome` and `WithProviderAuthRoot`. Under
`WithHostAuthority` the capability is omitted and those methods
follow the ordinary method-not-found path. Browser launchers remain shadowed by
the session browser shim.
